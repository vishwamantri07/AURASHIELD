# 🛡️ AURASHIELD

## Women Safety & Emergency Assistance

AURASHIELD is a women safety and emergency assistance platform designed to help users quickly access emergency support and improve personal safety.

## 🚨 Key Features

- 🆘 SOS Emergency Alert
- 📍 Live Location Sharing
- 👥 Emergency Contacts
- 🗺️ Safe Route Support
- 📢 Incident Reporting
- 📞 Emergency Assistance

## 💡 Problem Statement

Women may face safety risks in public places, during travel, or in emergency situations. AURASHIELD provides quick and accessible safety features to help users respond during emergencies.

## 💻 Technology Stack

- HTML
- CSS
- JavaScript

## 🎯 Expected Impact

- Faster emergency communication
- Improved personal safety
- Easy access to emergency features
- Better support during critical situations

## 🔮 Future Scope

- Mobile application
- Real-time location tracking improvements
- Integration with emergency services
- Additional safety and reporting features
